## Het project

Tijdens mijn werk bij Bertels Holland
heb ik gewerkt aan PS Forms,
oftewel Promo Sample Forms.

PS Forms is een interne bestelapplicatie
waarmee accountmanagers bestellingen
voor klanten kunnen aanmaken.

De applicatie is gebouwd met Laravel
en Statamic en maakt gebruik van
gegevens uit Teamleader CRM en Shopify.

Via een microservice en verschillende
API-integraties worden deze systemen
met elkaar verbonden.

Vanwege het interne karakter van
de applicatie kan ik niet alle
technische details delen.

## Achter de schermen

Een belangrijk onderdeel van PS Forms
is de integratie met Shopify.

Via de GraphQL API worden producten
uit Shopify opgehaald en vervolgens
gecached in een microservice.

Deze gegevens worden daarna gebruikt
om dynamisch Statamic-entries aan
te maken binnen de applicatie.

Hierdoor zijn de producten uit
Shopify beschikbaar binnen PS Forms,
zonder dat de applicatie bij iedere
aanvraag opnieuw de Shopify API
hoeft aan te roepen.

Daarnaast maakt PS Forms gebruik
van gegevens uit Teamleader CRM.

De applicatie brengt daarmee
verschillende externe systemen
samen binnen één interne
bestelomgeving voor accountmanagers.
